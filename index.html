Gestiona tus mantenimientos sin complicaciones

REVIQO es la app móvil definitiva para Android desarrollada en Kotlin y Jetpack Compose. Organiza clientes, equipos y programa alertas inteligentes en segundo plano.

Descargar APK Oficial Ver Código Fuente

Diseñado para el trabajo de campo

Potente por dentro, minimalista y rápido por fuera.

Directorio de Clientes Integrado

Gestiona la información de tus clientes con accesos directos integrados, incluyendo comunicación rápida vía WhatsApp para notificar avisos o citas de mantenimiento.

Control Exhaustivo de Equipos

Vincula múltiples equipos a tus clientes para realizar un seguimiento técnico detallado y organizado de cada dispositivo o instalación.

Alertas en Segundo Plano

Gracias a WorkManager, la app supervisa y te avisa de los mantenimientos pendientes de forma autónoma para que no se te pase ninguna fecha clave.

Datos Seguros, CSV y Backups

Todo se almacena localmente en tu dispositivo mediante Room Database. Además, puedes exportar e importar tus datos mediante archivos CSV y realizar copias de seguridad completas.

¿Cómo instalar REVIQO en tu móvil?

Instalación rápida en menos de 1 minuto.

01

Descarga el APK

Pulsa en el botón superior de descarga para obtener la última versión oficial directamente desde los releases de GitHub.

02

Permite orígenes desconocidos

Si tu Android te avisa por seguridad al instalar aplicaciones fuera de Google Play, pulsa en "Permitir desde esta fuente".

03

¡Listo para usar!

Abre la aplicación y comienza a registrar tus primeros clientes, equipos y mantenimientos programados.

Preguntas Frecuentes

Todo lo que necesitas saber sobre el proyecto.

¿REVIQO es totalmente gratuito?
Sí, REVIQO es un proyecto de código abierto bajo la Licencia Apache 2.0, lo que significa que es libre de usar, modificar y distribuir.
¿Necesito conexión a Internet para usarla?
No. Al utilizar Room Database, toda la información de tus clientes y equipos se guarda de forma local en tu dispositivo, funcionando perfectamente offline.
¿Cómo se actualiza la aplicación?
Puedes volver a esta página web o visitar el repositorio en GitHub para descargar manualmente la última versión disponible del archivo APK.
